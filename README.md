# 🎬 YouTube Homepage Clone

A YouTube-inspired homepage built using **HTML5 and CSS3**, 
recreating the familiar layout and visual design of YouTube. 
This project focuses on front-end development, CSS layouts, and building clean, structured web interfaces.

## 🚀 Features

- YouTube-inspired homepage design
- Header with search bar and navigation icons
- Sidebar with Home, Explore, Subscriptions, and other sections
- Video grid displaying thumbnails, titles, and channel information
- Video duration labels and view counts
- Clickable video thumbnails linking to YouTube
- Hover tooltips for header controls

## 🛠️ Technologies Used

- **HTML5** – Page structure and content
- **CSS3** – Styling, Flexbox, Grid, and layout
- **Google Fonts** – Roboto typography

## 💻 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Anas1125/youtubes.git
   ```
2. Open the `youtubes` folder.
3. Open `index.html` in your web browser.

No installation or additional dependencies are required.

## 🎯 Project Objective

This project was developed to strengthen my understanding of HTML and CSS, practice layouts using Flexbox and Grid, and gain experience recreating real-world website interfaces.

## 📌 Note

This is a front-end UI clone created for educational purposes. It is not affiliated with YouTube or Google. Features such as searching, authentication, and video uploading are not implemented.
